# Preliminary name screen: QC Remote

Screened 2026-09-13. This is an engineering issue-spotting record, not a
trademark clearance opinion, legal advice, or a substitute for a jurisdiction-
specific search by a qualified trademark professional.

## Executive conclusion

**Do not treat `QC Remote` as cleared for public release.** The exact phrase did
not appear in the U.S. or EU registry searches recorded below, but the name is
descriptive and unusually close to the registered product name it is intended
to control. Neural DSP Technologies Oy owns live `QUAD CORTEX` registrations
covering overlapping downloadable software and hardware. In this market, `QC`
is readily understood as an abbreviation of `Quad Cortex`; adding `Remote`
describes the app's function. A disclaimer reduces affiliation confusion in
context but does not itself make a confusingly similar product name safe.

There is also a separate market collision: KLIPPEL already uses **QC Remote
Configuration Software** for software used with audio quality-control systems.
Even if the companies' precise goods and customers differ, that use makes the
proposed name less distinctive and creates search, store, and support confusion.

If professional clearance is not available, the materially safer engineering
choice is a distinctive coined name that does not begin with `QC`, with `for
Quad Cortex` used only as a subordinate compatibility statement where lawful.

## Registry searches performed

### United States — USPTO Trademark Search

Interactive searches were performed in the official USPTO Trademark Search on
2026-09-13:

- `CM:"QC REMOTE"` — no results.
- `CM:(QC AND REMOT*)` — no results.
- `CM:"QUAD CORTEX"` — four results, including two live registrations owned by
  Neural DSP Technologies Oy: serial 97977302 for downloadable music software
  in International Class 009 and serial 88925551 for amplifier/effects-modeling
  hardware in Class 009. The results also included a live pending `QUAD CORTEX
  MINI` application and one dead `QUAD CORTEX` application.

The USPTO itself describes an exact-wording search as only a “knock-out” search
and says not to stop there. The no-result exact search therefore is not evidence
that the proposed name is available.

### European Union — EUIPO eSearch plus

Interactive searches were performed in the official EUIPO eSearch plus system
on 2026-09-13:

- `QC Remote` — zero trade marks returned by the basic search.
- `Quad Cortex` — three EU trade marks owned by Neural DSP Technologies Oy:
  EUTM 018255049, registered in Class 009; EUTM 018644171, registered in Classes
  015, 025, 035, and 042; and EUTM 019306076 (`QUAD CORTEX MINI`), registered in
  Class 009.

### Not completed

This screen does not cover national registries outside the U.S. and EU, common-
law use comprehensively, company-name registers, domains, social handles,
marketplaces, source-code hosts, or app stores. It does not include a similarity,
phonetic, translation, design-mark, owner, opposition, cancellation, or full
goods-and-services analysis. WIPO Madrid/Global Brand Database and relevant
national registries must still be searched for every launch market.

## Likely goods and services scope

Under the Nice Classification, the present downloadable desktop and Android
software belongs primarily in Class 009. Class 042 becomes relevant if the
publisher offers SaaS, hosted AI, or other software services under the name.
Class 015 is not the primary class for the current software: the Class 015 note
specifically places electronic effects units for musical instruments in Class
009. Final identifications must describe the actual release, not merely copy a
class heading.

## Required publisher decision

Before setting `nameClearanceCompleted` to `true` in
`legal/public-release.json`, retain a dated search report covering all launch
markets and proposed goods/services, resolve the Neural DSP and KLIPPEL risks,
and document the publisher's decision. Also search and reserve the final app
store names, domains, social handles, support identities, and replacement
application identifiers. A registry filing or approval is not by itself a
guarantee against third-party claims.
