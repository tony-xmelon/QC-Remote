# Security policy

QC Remote has no supported public release while its security, ownership,
licensing, and distribution review remains incomplete.

Do not post suspected vulnerabilities, credentials, tokens, private device data,
or exploit details in a public issue or pull request. Use GitHub's
[private vulnerability report](https://github.com/tony-xmelon/QC-Remote/security/advisories/new)
for this repository. Reports submitted there are visible to repository
maintainers rather than posted as public issues. Do not include unrelated user,
device, account, or third-party proprietary data; provide only what is needed to
reproduce and assess the security problem.

A publisher-operated security contact and finalized response policy have not
yet been published. Before a supported public release, Freevia must identify
response ownership and expectations and publish both a monitored
`securityEmail` and an HTTPS `securityPolicyUrl`; placeholder or missing values
fail the public-release gate. GitHub reporting is an interim and supplementary
channel, not a promise of a current response time or supported-release status.

If the GitHub form is unavailable and disclosure is necessary to prevent urgent
harm, remove secrets and personal or proprietary data and share only the minimum
information required through a private channel independently verified as
belonging to the repository owner.
